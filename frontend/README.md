# AfriSoro Frontend

Next.js 14 frontend for AfriSoro platform.

## Setup

```bash
npm install
cp .env.example .env
# Edit .env with NEXT_PUBLIC_API_URL
npm run dev
```

App runs on http://localhost:3000

## Environment Variables

- `NEXT_PUBLIC_API_URL` - Backend API URL (default: http://localhost:5000)
